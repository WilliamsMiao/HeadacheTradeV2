# MACD 多周期策略职责

HeadacheTradeV2 只生成交易建议和模拟持仓，不接实盘自动下单，也不构成投资建议。

## 周期分工

| 周期 | 职责 | 是否参与核心交易 |
| --- | --- | --- |
| 1D | 大盘状态、个股趋势权限、日线风险提示 | 是 |
| 60m | MACD 顶底结构识别 | 是 |
| 15m | 底结构确认后的趋势恢复触发 | 是 |
| 5m | 工作台展示和执行辅助 | 否 |

大盘决定能不能做，日线决定个股是否有做多权限，60m 结构决定是否进入观察，15m 触发决定是否可以生成入场候选。

## 当前 PR 边界

PR 1 已统一周期定义，并将 15m 接入行情、指标和数据完整性检查。60m 结构字段增强、15m 状态机触发、结构止损、纠错和时间步进回测将在后续 PR 按顺序实现。

## 不变约束

- 评分只展示，不参与状态转换或买卖。
- 底结构不能直接买入。
- 顶结构不能直接清仓。
- 大盘过滤不可跳过。
- 无止损不得生成入场建议。
- 不引入 FVG、Volume Profile、Order Flow、ICT、Wyckoff、Harmonic、Fibonacci 等战法进入主链路。
