# MACD 多周期策略职责

HeadacheTradeV2 只生成交易建议和模拟持仓，不接实盘自动下单，也不构成投资建议。

## 周期分工

| 周期 | 职责 | 是否参与核心交易 |
| --- | --- | --- |
| 1D | 大盘状态、个股趋势权限、日线风险提示 | 是 |
| 60m | MACD 顶底结构识别 | 是 |
| 15m | 底结构确认后的趋势恢复触发 | 是 |
| 5m | 工作台展示和执行辅助 | 否 |

大盘决定能不能做，日线决定个股是否有做多权限，60m 结构决定是否进入观察，15m 触发决定是否可以生成入场候选。

## 当前实现边界

PR 1 已统一周期定义，并将 15m 接入行情、指标和数据完整性检查。

PR 2 为 60m 结构事件增加：

- `pivot_low / pivot_high`；
- `confirm_level`；
- `invalidation_level`；
- `trigger_level`；
- `parent_event_id`；
- `expires_at`；
- `script_version`。

PR 3 已将入场链路改为：

1. 1D 提供市场与个股趋势权限；
2. 60m `BOTTOM_STRUCTURE` 进入底结构确认；
3. 状态机进入 `WAIT_15M_TRIGGER`；
4. 15m 趋势恢复触发通过后，才允许风控模块生成 `ENTRY_CANDIDATE`。

15m 触发至少检查 MA20、最近 8 根高点、MACD 柱连续改善、DIF 方向、量能和结构失效位距离。ENTRY 原因记录结构与触发来源，评分仍不参与任何条件。

PR 4 已将剧本 A 的止损绑定到 60m 底结构：

- 止损价为 `pivot_low - 0.5 × 60m ATR`；
- ATR 使用结构确认时点对应的 60m 指标；
- 无结构低点、无 ATR、无结构来源或无 15m 触发来源时不得生成 ENTRY；
- ENTRY 单独记录每股风险、允许亏损、实际风险、建议市值和仓位比例；
- 剧本 B 继续使用更低风险乘数，并预留更紧的顶结构失效突破止损。

PR 5 已增加失败后的纠错规则：

- 底结构失败会取消关联的 pending ENTRY 并进入冷却；
- 15m 触发快速失败会取消未审批建议；
- pending ENTRY 超过 4 根 15m K 自动过期；
- 市场降级会取消未审批 ENTRY，并让已有持仓进入风险保护；
- 市场降级且个股跌破 60m MA60 时，只生成退出候选，不自动下单。

所有取消和过期均保留原建议并记录原因。

PR 6 已将回测改为隔离的时间步进回放。回放按 K 线完成时间暴露数据，逐步运行同一套市场、趋势、结构、触发、纠错和状态机规则，并保存每笔交易的完整结构来源、触发来源、入场、退出与 R 倍数。

## 不变约束

- 评分只展示，不参与状态转换或买卖。
- 底结构不能直接买入。
- 顶结构不能直接清仓。
- 大盘过滤不可跳过。
- 无止损不得生成入场建议。
- 不引入 FVG、Volume Profile、Order Flow、ICT、Wyckoff、Harmonic、Fibonacci 等战法进入主链路。
